News

2026-11-07

All 25,065 lines of the text now have their position on the page image (obtained by aligning OCR output with the text lines; the characters of the text are unchanged). The image viewer on the text pages has been renewed: clicking a line of the text highlights that line on the image and zooms to it. Click it again or press Esc to clear the highlight. The line positions are included in the TEI/XML as <zone type="line">.

2026-11-06

The site has been rebuilt following the Endings Principles for digital longevity. Libraries that used to be loaded from external services are now bundled with the site, and pages such as the waka list can be read without JavaScript. The English pages now live under en/, and links to pages and poems take the form html/01.html#p13 and #waka-001 (the old URLs still work). Every page shows its version and DOI, and a How to Cite section has been added. The published HTML is validated with the W3C Nu HTML Checker, and all internal links are checked.

2026-08-12

The TEI schema has been thoroughly revised. The previous schema was defective: all 795 waka failed validation against it (the text data itself was never at fault). We also introduced Schematron validation, which now mechanically checks the number of lines in each waka, line numbering, the ordering of page numbers, and referential integrity. All 54 chapters are validated automatically before publication. See Technical Information for details.

2026-03-08

Corrected typos and waka notation in the text based on user feedback. Added a Waka Poems page and a Visualizations page, along with PDF and EPUB viewing and download support for each volume.

2025-06-23

The website design has been modernized and DTS (Distributed Text Services) support has been added. Responsive design and accessibility have also been improved.

About This Site

Text data was created and published based on the 'Kōi Genji Monogatari' (Collated Genji Monogatari) (Internet publication, copyright expired) available in the National Diet Library Digital Collection.

Each line is assigned a URI (Uniform Resource Identifier) and published as LOD (Linked Open Data). TEI/XML files linked with IIIF images are also provided.

If you find any errors in the data, please contact The University of Tokyo Academic Asset Archiving Promotion Office at digital-archive [at] lib.u-tokyo.ac.jp.

How to Cite

This is version 1.4.0, released on 2026-11-07. Please cite it as follows.

校異源氏物語テキストDB / Koui Genji Monogatari Text Database (2026). Version 1.4.0 [Data set]. Zenodo. https://doi.org/10.5281/zenodo.24015761

The DOI above always leads to the latest version on Zenodo. To cite this exact version, use the version number above, or the DOI of the version listed under "Versions" on the Zenodo record.

To cite a single line, add the URI of that line, e.g. https://w3id.org/kouigenjimonogatari/api/items/0009-03.json (volume 1, page 9, line 3).

The same information is in CITATION.cff; GitHub and Zenodo show it as "Cite this repository".

Technical Information

The TEI/XML in this database is defined by an ODD (One Document Does it All) as the single source of truth. Both the RELAX NG schema and the Schematron rules are generated from that ODD, and all 54 chapters are validated against both before publication.

  • tei_kouigenji.odd
    The custom ODD. Declares the TEI elements and attributes in use, together with constraints a grammar cannot express (a waka has five lines, every pointer resolves, and so on). This is the only file that is edited by hand.
  • tei_kouigenji.rng
    RELAX NG schema for structural validation, generated from the ODD.
  • tei_kouigenji.sch
    ISO Schematron rules for what a grammar cannot check: line numbering against position, monotonic page numbers, and referential integrity.
  • tei_kouigenji.html
    Browsable documentation of the customization: elements, attributes and constraints.

Generated with the official TEI Stylesheets (7.61.0) and SchXslt2 (1.11.2), against TEI P5 4.12.0. The source is available in the GitHub repository. All volumes can also be browsed through the DTS (Distributed Text Services) viewer.
